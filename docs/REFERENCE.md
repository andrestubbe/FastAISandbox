# FastAISandbox Reference & API Specification

## 1. Core Vocabulary

*   **Sandbox**: An isolated execution boundary restricting CPU time, RAM allocation, and allowed system calls.
*   **Virtual Filesystem Jail**: An isolated temporary directory tree preventing path traversal outside the approved workspace.
*   **ExecutionPolicy**: A deterministic ruleset defining disallowed commands, execution deadlines, and memory quotas.
